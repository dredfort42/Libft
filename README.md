# Libft

This project implements common C standard library functions to help you understand their behavior and build a reusable library for future C projects.

## Implemented functions

-   Character classification & conversion
    -   `isalpha`, `isdigit`, `isalnum`, `isascii`, `isprint`, `toupper`, `tolower`
-   Memory management
    -   `memset`, `bzero`, `memcpy`, `memmove`, `memchr`, `memcmp`, `calloc`
-   String handling
    -   `strlen`, `strlcpy`, `strlcat`, `strchr`, `strrchr`, `strncmp`, `strnstr`, `strdup`
-   Conversion
    -   `atoi`

Feel free to open an issue or submit a PR for improvements or additions.
